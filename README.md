**🏅 成长足迹（孩子侧的进步可视化）**：主页新卡，把学习数据翻译成孩子的语言——自动头条播报（"口算新纪录！""这周比上周多学 3 个词"）、本周航行 7 格灯、词汇量与待消灭错题、"下一个目标"进度条（点亮行星/新徽章等最近的可达目标）。点开有近 4 周航行记录和各星系进度。只夸努力与进步、不展示错误率曲线——错误以"待消灭的老对手"任务形式呈现。详细数据曲线仍在家长面板。

- **空间站（首页）**：今日任务卡列出**三主科**（英语学词复习 / 60 秒口算 / 语文一轮）的进度和入口，完成任意一科即打卡盖章，三科全达额外 +10 金币；下方"学科星系"宫格是各科入口（数学/语文/科学/道法）。金币可以给机器伙伴喂能量块，喂够次数会进化。

## 题库（词库）怎么维护

**方式一：自定义词（推荐日常用，无需改代码）**
家长面板 → ✨添加自定义词，每行一个词粘贴即可。分隔符用 `|`、Tab 或英文逗号均可自动识别（例句里含逗号时请用 `|`）：

```
单词|中文|表情|例句|例句中文     ← 后四项都可省略
tiger|老虎
cup|杯子|🍵|This is my cup.|这是我的杯子。
```

只写 `单词|中文` 也行，表情和例句会自动补默认值。建议在 Excel 里维护一列词表，整列复制粘贴进来。已导入的词显示在「我的星系」，可单独删除（改一个词 = 删了重新加）。

**方式二：修改内置 7 大星系（需要动文件）**
内置词库在 `js/data.js` 里，每个星系一段，照着已有格式增删改单词即可（用记事本/VS Code 打开）。改完记得把 `sw.js` 的缓存版本号 +1。不方便自己改的话，直接把词表发给我来改。

**方式三：确定教材版本后做"同步词包"**
告诉我学校教材的确切版本（外研社一年级/三年级起点、北师大、沪教牛津…），最好拍下课本最后的词汇表，我按"单元=星系"录入，孩子学哪课就练哪课。

## 在 iPad / 安卓平板 / 手机上使用

1. 电脑双击 `启动学习站.bat`（保持开机），用 `ipconfig` 查到电脑的 IPv4 地址（如 `192.168.1.8`）；
2. 平板/手机连**同一个 Wi-Fi**，浏览器访问 `http://192.168.1.8:8123`；
3. 在浏览器菜单里点 **"添加到主屏幕"**（iPad 用 Safari 的分享按钮）。之后从主屏幕图标打开：全屏运行、断网可用。

注意事项：
- **请始终从主屏幕图标进入**（iOS 上不要一直在 Safari 标签页里用，也不要开无痕浏览），否则 iOS 可能在 7 天后清掉学习数据；
- 学习进度存在**每台设备各自**的浏览器里，不跨设备同步。建议固定一台设备给孩子用；换设备时用家长面板的「导出备份 / 导入备份」迁移；
- 局域网方式要求电脑开机。想彻底摆脱电脑，可以把整个文件夹发布到 GitHub Pages（免费静态托管，仍然没有后端，数据照旧只存设备本地），需要的话我来帮你部署。

## 技术说明

- 纯静态页面（HTML/CSS/原生 JS，零依赖、零构建），数据存 localStorage
- 发音用浏览器内置 TTS（speechSynthesis），离线可用
- PWA：`manifest.webmanifest` + `sw.js`（仅在 http://localhost 或 HTTPS 下生效）
- 以后修改了代码/词库，需要把 `sw.js` 里的 `star-english-v1` 改成 `v2`、`v3`…（递增即可），否则老设备会继续用缓存的旧版本
- 间隔复习用简化 Leitner 盒子：答对间隔 1→2→4→7→15 天递增，答错退回一天后重见
