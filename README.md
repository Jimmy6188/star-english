# 星际求知号 🚀

**在线地址：https://jimmy6188.github.io/star-english/** （GitHub Pages，平板/手机直接打开后"添加到主屏幕"即可全屏离线使用）

给 9 岁小学生的英语学习小世界：打卡闯关、字母块拼词、收集星际贴纸、喂养进化机器伙伴。
纯本地网页应用，无需联网、无需服务器，学习数据只存在本设备浏览器里。

## 怎么启动

**推荐（平板/手机）：** 浏览器打开上面在线地址 → 菜单里选 **"添加到主屏幕"**。之后从主屏幕图标进入：全屏、离线可用，电脑不用开机。

**电脑上：** 双击 `启动学习站.bat`（会自动打开浏览器），或直接双击 `index.html`。

## 玩法（孩子侧）

**🏅 成长足迹（孩子侧的进步可视化）**：主页新卡，把学习数据翻译成孩子的语言——自动头条播报（"口算新纪录！""这周比上周多学 3 个词"）、本周航行 7 格灯、词汇量与待消灭错题、"下一个目标"进度条（点亮行星/新徽章等最近的可达目标）。点开有近 4 周航行记录和各星系进度。只夸努力与进步、不展示错误率曲线——错误以"待消灭的老对手"任务形式呈现。详细数据曲线仍在家长面板。

**🪐 数学星系（多学科第一站）**：首页的"限时口算冲刺"，按四上进度程序生成题目（三档难度、冲刺时长家长可调）。60 秒答对越多越好，答对赚金币、错题进错题池下次优先重练；答对 ≥10 题的冲刺累计点亮行星（10 颗收集线）。**打卡共享**：完成英语任务或口算冲刺任一即盖章，金币、宠物、徽章、段位全部通用。

- **空间站（首页）**：每天的任务卡（学几个新词 + 复习旧词），完成后打卡盖章、领金币；金币可以给机器伙伴喂能量块，喂够次数会进化。
- **冒险（任务流）**：新词先听发音看例句 → 可选"🎤跟读试试"录下自己的声音和标准发音回放对比（每词首次自评"读得像"奖 3 金币；需要麦克风权限和 https/localhost 环境）→ 进入拼写舱拼词；拼对触发"传送成型"，贴纸飞进图鉴（约 10% 概率金色超新星贴纸）。复习关随熟练度升级：听音选图→看图选词→句子填空→带干扰字母拼写→听写挑战；词组走"组装舱"。
- **星际图鉴**：按主题分为 8 大星系 136 个词（覆盖 1~6 年级），没学过的显示为黑色剪影，收集欲拉满；点开的贴纸可以再听发音和例句。
- **航行日志**：打卡月历，每天一枚火箭章；连续天数 + 护盾（每周自动补充 2 张，漏打卡时自动保住连击）。

## 家长侧

首页底部导航「家长」进入，初始 PIN **1234**（请第一时间修改）：

- 学习概览：已学词数、今日待复习、正确率、连续打卡、当前段位、本周 BOSS、近 7 天时长图
- **年级与词汇范围**：设置孩子年级后，新词默认"当前年级 + 低年级温故"（低年级词先出现当热身，学习卡上标注「温故/挑战」徽章）；也可切换为只学当前年级，或开放全部词库（含高年级挑战词）。词库覆盖 1~6 年级 142 词、8 大星系（含数字星系）
- **教材同步词包（外研版新标准三起 2024审定）**：`js/data.js` 里的 `TEXTBOOK_PACKS` 按 Module 录入课本单词和**词组**，教材词会**优先出题**（每轮新词教材包先出 2 个）。词组用"组装舱"挑战：把打乱的单词块按顺序排好；词组同样进图鉴、复习和错题本
- **段位晋升**（学有余力的成长线）：见习飞行员 → 飞行员 → 精英飞行员 → 王牌飞行员 → 星际指挥官，按累计已学词数自动晋升，晋升有弹窗庆祝和金币奖励
- **周日 BOSS 挑战**：每周日首页出现 👑 挑战卡，10 道高阶大题（听写/干扰字母/句子填空），失误 2 次以内通关 +50 金币，记录每周最佳成绩——这是给"正确率很高"的孩子的定期拔高
- **高正确率提醒**：正确率 ≥92% 且已学 ≥30 词时，家长面板会建议开放全部词库（加入高年级挑战词）
- **错题本**：自动记录孩子反复出错的词（错几次、是否在连错中）。这些词在每日复习里会**优先出现**；首页会出现「⚡错词来袭」挑战卡，点进去专项击破，全部答对即洗清连错并自动移出错题本；图鉴里这些词会带红色小圆点
- 复习题型随熟练度自动升级：刚学的词是"听音选图"；熟一点变成"看图选词"；再熟是"句子填空"和"带干扰字母的拼写"；很熟的词直接"听写挑战"（隐藏中文，靠发音拼写）
- 学习设置：每天新词数 / 复习量 / 单次时长提醒
- 词库管理：7 大星系可开关；"添加自定义词"支持批量粘贴
- **兑换商店**：定义孩子可用金币兑换的现实奖励（如周末冰淇淋），孩子发起兑换、家长确认兑现，支持拒绝退还；形成"努力→攒币→兑现"的完整闭环
- **成长曲线**：家长面板内查看词汇量增长折线（近 14 天）与口算成绩走势
- 数据备份：导出 / 导入 JSON；可清空学习进度或恢复出厂

**🧾 今日结算单**：孩子在任意页面点击顶部的金币徽章，弹出当天的小票式结算单——各学科完成情况、今日金币收入、用时、连续航行、明天待复习。

## 题库（词库）怎么维护

**方式一：自定义词（推荐日常用，无需改代码）**
家长面板 → ✨添加自定义词，每行一个词粘贴即可。分隔符用 `|`、Tab 或英文逗号均可自动识别（例句里含逗号时请用 `|`）：

```
单词|中文|表情|例句|例句中文     ← 后四项都可省略
tiger|老虎
cup|杯子|🍵|This is my cup.|这是我的杯子。
```

只写 `单词|中文` 也行，表情和例句会自动补默认值。建议在 Excel 里维护一列词表，整列复制粘贴进来。已导入的词显示在「我的星系」，可单独删除（改一个词 = 删了重新加）。

**方式二：修改内置 7 大星系（需要动文件）**
内置词库在 `js/data.js` 里，每个星系一段，照着已有格式增删改单词即可（用记事本/VS Code 打开）。改完记得把 `sw.js` 的缓存版本号 +1。不方便自己改的话，直接把词表发给我来改。

**方式三：确定教材版本后做"同步词包"**
告诉我学校教材的确切版本（外研社一年级/三年级起点、北师大、沪教牛津…），最好拍下课本最后的词汇表，我按"单元=星系"录入，孩子学哪课就练哪课。

## 在 iPad / 安卓平板 / 手机上使用

1. 电脑双击 `启动学习站.bat`（保持开机），用 `ipconfig` 查到电脑的 IPv4 地址（如 `192.168.1.8`）；
2. 平板/手机连**同一个 Wi-Fi**，浏览器访问 `http://192.168.1.8:8123`；
3. 在浏览器菜单里点 **"添加到主屏幕"**（iPad 用 Safari 的分享按钮）。之后从主屏幕图标打开：全屏运行、断网可用。

注意事项：
- **请始终从主屏幕图标进入**（iOS 上不要一直在 Safari 标签页里用，也不要开无痕浏览），否则 iOS 可能在 7 天后清掉学习数据；
- 学习进度存在**每台设备各自**的浏览器里，不跨设备同步。建议固定一台设备给孩子用；换设备时用家长面板的「导出备份 / 导入备份」迁移；
- 局域网方式要求电脑开机。想彻底摆脱电脑，可以把整个文件夹发布到 GitHub Pages（免费静态托管，仍然没有后端，数据照旧只存设备本地），需要的话我来帮你部署。

## 技术说明

- 纯静态页面（HTML/CSS/原生 JS，零依赖、零构建），数据存 localStorage
- 发音用浏览器内置 TTS（speechSynthesis），离线可用
- PWA：`manifest.webmanifest` + `sw.js`（仅在 http://localhost 或 HTTPS 下生效）
- 以后修改了代码/词库，需要把 `sw.js` 里的 `star-english-v1` 改成 `v2`、`v3`…（递增即可），否则老设备会继续用缓存的旧版本
- 间隔复习用简化 Leitner 盒子：答对间隔 1→2→4→7→15 天递增，答错退回一天后重见
